HAN 포트폴리오 홈페이지 — 시작 안내

파일
- index.html: PC/모바일 메인 페이지
- project.html: 프로젝트 상세페이지 템플릿
- style.css: 전체 디자인과 반응형 레이아웃
- script.js: 모바일 메뉴, 작품 패널 호버, 상세페이지 데이터, 갤러리 확대 기능

실행 방법
1. ZIP 압축을 풉니다.
2. VS Code에서 압축을 푼 portfolio_homepage 폴더를 엽니다.
3. index.html을 브라우저에서 열어 확인합니다.
   권장: VS Code의 Live Server 확장 기능을 설치하고 index.html에서
   마우스 오른쪽 버튼 > Open with Live Server를 선택합니다.

현재 상태
- Figma 레이아웃을 기준으로 한 구현용 초안입니다.
- 노란색 영역은 최종 이미지/영상이 준비되기 전의 임시 자리표시자입니다.
- 프로젝트 제목과 설명은 임시 문구이며, 최종 콘텐츠에 맞게 교체해야 합니다.
- 상세페이지는 project.html?project=0~3으로 4개 프로젝트를 표시합니다.
- 실제 영상 재생은 아직 연결하지 않았습니다. 최종 영상 파일 또는 영상 URL이 준비되면 추가합니다.
- 폰트는 Inter를 사용하며, Google Fonts 연결이 차단된 환경에서는 시스템 폰트로 표시됩니다.

권장 작업 순서
1. 브라우저에서 PC/모바일 화면 확인
2. Figma와 간격/크기 비교 및 CSS 조정
3. 최종 이미지와 영상 적용
4. 실제 프로젝트 정보 반영
5. 모든 링크와 접근성 테스트
6. 배포
